B. TOP 3 REALISM GAPS

1. **Learning update mechanism from detection** – The description states agents update behavior based on rewards and penalties but does not specify how detection events modify the Q-values for AI-assisted vs. direct copying. This gap matters because the detection probabilities are central to the findings about prevalence; without knowing if detection reduces future AI-plagiarism or if agents learn to evade detection, the behavioral dynamics remain under-specified. This is a hypothesis needing more information.

2. **Nature and structure of the active intervention** – The experiment compares a no-intervention condition with an active-intervention condition, yet the description offers no details on the intervention’s content, timing, or target (e.g., feedback, sanctions, education). This gap matters because the main finding—that AI-assisted plagiarism remains prevalent under intervention—cannot be evaluated without knowing what the intervention actually does; the result could reflect a weak or misaligned intervention rather than a model feature. This is a hypothesis needing more information.

3. **Peer network topology and influence dynamics** – While students interact through local peer networks, the description provides no details on network structure (e.g., density, tie strength) or the mechanism of influence (e.g., observational learning, conformity pressures). This gap matters because network structure critically shapes the diffusion of dishonest behavior; assuming a default topology could either exaggerate or mask the effects of intervention. This is a hypothesis needing more information.

C. ONE MINIMUM REVISION

Add a single sentence to the model specification: "When a student is detected plagiarizing, their Q-values for the detected behavior are reset to the baseline honest-submission level for the next decision cycle." Evaluate the revision by running the simulation with and without this reset mechanism; if the prevalence of AI-assisted plagiarism under the active-intervention condition decreases meaningfully compared to the current setup, the revision improves realism by grounding the learning update in a plausible consequence of detection.
